This project is an NBA players' salary prediction app built using Python. The app predicts the salaries of NBA players based on their statistics and other relevant features.

## ✨ Features

- **Machine Learning Algorithms**: Implements Random Forest, Linear Regression, and other models to provide accurate salary predictions.
- **Interactive UI**: Built using Streamlit, allowing users to input player features and view predictions in real time.
- **Data Visualization**: Visualizes relationships between features and predicted salaries using various charts and plots.
- **Model Evaluation**: Uses evaluation metrics like R-squared, Mean Squared Error (MSE), etc., to measure model performance.

## 🛠️ Technologies Used

- **Streamlit**: For building the interactive user interface.
- **Jupyter Notebook**: For data analysis, preprocessing, and model development.
- **Python**: Used for building and deploying machine learning models.
- **Pandas**: For data manipulation and cleaning.
- **Scikit-learn**: For implementing machine learning algorithms.

## 🚀 Getting Started

1. **Clone the repository**  
   ```bash
   git clone https://github.com/ajayrajrthd/Salary_Prediction.git
   ```
2. **Navigate to the project directory**  
   ```bash
   cd Salary_Prediction
   ```
3. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Streamlit app**  
   ```bash
   streamlit run app.py
   ```
